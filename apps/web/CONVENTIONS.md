# Coding Conventions

This document outlines the coding conventions used in this application. Please
follow these conventions when contributing to the web app.

## Frontend

- Use React function components.
- Use React Router for routing.
- Use react-daisyui for UI components where possible.
- Use tailwind css utilities for styling that is not already handled by
  react-daisyui.

## Backend

- Use Drizzle ORM for database access.
- Use Drizzle Kit for database migrations.
- Use Zod for validation.
